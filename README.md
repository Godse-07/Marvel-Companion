# Marvel Companion

Bring your favorite superhero companions into your Visual Studio Code workspace!

Marvel Companion lets you choose a character to display in a dedicated companion panel while you code.

## ✨ Features

- **Character Selection:** Choose from Spider-Man, Iron Man, Thor, and Black Panther.
- **Change Characters:** Switch characters whenever you want using the Command Palette.
- **Custom Character Sizes:** Iron Man uses a smaller display size, while the other characters retain the standard size.
- **Spider-Man Web Effect:** A web thread is displayed for Spider-Man only.
- **Remember Your Choice:** Your last selected character is saved for your workspace.

## 🚀 Getting Started

1. Install Marvel Companion.
2. Open the Command Palette with `Ctrl + Shift + P` (Windows/Linux) or `Cmd + Shift + P` (macOS).
3. Run **Marvel Companion: Choose Character**.
4. Select your preferred character.
5. To switch characters, run **Marvel Companion: Change Character**.

## 🖼️ Supported Characters

- Spider-Man
- Iron Man
- Thor
- Black Panther

## ⚙️ Requirements

- Visual Studio Code version compatible with this extension.
